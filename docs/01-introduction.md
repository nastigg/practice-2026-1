# Введение

3D-рендеринг — это процесс преобразования трёхмерной сцены в двумерное изображение.

В данном проекте реализуется программный рендерер "с нуля", чтобы понять:
- как работают графические движки
- как происходит преобразование координат
- как рисуются полигоны

## Цель
Создать минимальный 3D-движок без сторонних библиотек.
