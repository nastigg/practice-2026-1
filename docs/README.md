# Build Your Own 3D Renderer (Java / JavaScript)

## Описание проекта
Цель проекта — разработать собственный 3D-рендерер с нуля без использования готовых графических движков (OpenGL, Three.js и т.п.).

Проект реализуется на: Java и JavaScript 

## Задачи
- Реализовать базовую 3D-математику
- Добавить проекции
- Реализовать освещение и тени
- Визуализировать 3D-сцены
