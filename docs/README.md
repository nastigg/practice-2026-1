# Документация

## Ray Tracer Project

## Описание
Данный проект выполнен в рамках учебной практики (проектно-технологическая).  
Цель — реализовать собственный ray tracer (трассировщик лучей) с нуля и изучить основы компьютерной графики.

## Возможности
- Генерация изображения с помощью лучей
- Отрисовка сфер
- Освещение (модель Фонга)
- Тени
- Отражения
- Антиалиасинг

## Технологии
- Язык: JavaScript
- Git
- Markdown
- HTML + CSS
