#Build Your Own 3D Renderer (Java / JavaScript)

## О проекте
Этот проект — пошаговое руководство по созданию собственного 3D-рендерера с нуля.

Вдохновлено:
- https://avikdas.com/build-your-own-raytracer/

## Что вы реализуете
- Рисование пикселей
- Линии и треугольники
- 3D-преобразования
- Камеру
- Перспективу
- Z-buffer
- Освещение

Понять, как работает графика "под капотом", без OpenGL и Three.js.
