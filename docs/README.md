## 2. Документация в формате Markdown

### Освоенные элементы Markdown

1. **Заголовки**  
   `# H1`, `## H2`, `### H3`

2. **Форматирование текста**  
   `**Жирный**`, `*Курсив*`, `~~Зачёркнутый~~`

3. **Списки**  
   Нумерованные:  
   `1. Пункт`  
   Маркированные:  
   `- Пункт`

4. **Ссылки и изображения**  
   `[Текст](https://example.com)`  
   `![Alt-текст](image.jpg)`

5. **Таблицы**  
   \| Заголовок \| Пример \|  
   \|----------\|--------\|  
   \| Ячейка   \| Данные \|  

6. **Блоки кода**  
   \```python  
   print("Hello!")  
   \```

## 4. Разработка 3D-рендерера на Java и JavaScript (вариативная часть)

### Задачи работы

Для достижения поставленной цели необходимо решить следующие задачи:

1. Изучить основы представления графической информации  
2. Реализовать вывод пикселей на экран  
3. Реализовать алгоритмы построения линий  
4. Реализовать работу с треугольниками  
5. Добавить поддержку трёхмерных координат  
6. Реализовать перспективную проекцию  
7. Разработать механизм отображения 3D-объектов  
8. Реализовать анимацию (вращение объекта)  


### Теоретические сведения

3D-рендеринг — это процесс преобразования трёхмерной сцены в двумерное изображение.

Основные этапы рендеринга:

1. Описание геометрии объекта (вершины, рёбра)  
2. Преобразование координат (вращение, масштабирование, перенос)  
3. Проецирование трёхмерных координат на плоскость экрана  
4. Растеризация (определение пикселей изображения)  
5. Отрисовка  

Перспективная проекция описывается следующими выражениями:

```bash
:contentReference[oaicite:0]{index=0}
```

### Описание реализации

#### 1. Отрисовка пикселей
Реализована базовая возможность вывода пикселей:
- в языке Java с использованием `BufferedImage`
- в JavaScript с использованием `Canvas API`

#### 2. Построение линий
Реализован алгоритм построения линий между двумя точками, позволяющий отображать рёбра объектов.

#### 3. Работа с треугольниками
Изучены принципы построения треугольников как базовых графических примитивов.

#### 4. Поддержка 3D-координат
Добавлена третья координата Z, что позволило перейти от двумерной графики к трёхмерной.

#### 5. Перспективная проекция
Реализовано преобразование координат из 3D в 2D с учётом перспективы.

#### 6. Реализация 3D-объекта
Создана модель куба, заданная набором вершин и рёбер.

#### 7. Анимация
Реализовано вращение куба вокруг оси, что позволяет визуализировать трёхмерность объекта.
