# Проект: Разработка 3D-рендерера (Java / JavaScript)

## Цель работы

Целью данной работы является изучение принципов работы 3D-графики и реализация собственного рендерера без использования готовых графических библиотек.

В ходе работы необходимо:
- изучить основы 3D-математики  
- реализовать pipeline рендеринга  
- научиться преобразовывать 3D → 2D  
- создать визуализацию сцены  


## Задачи

В процессе выполнения работы были поставлены следующие задачи:

- реализовать вывод пикселей на экран  
- реализовать отрисовку линий  
- реализовать треугольники  
- добавить 3D-координаты  
- реализовать перспективную проекцию  
- реализовать камеру  
- создать вращающийся 3D-объект  


## Теоретическая часть

3D-рендеринг — это процесс преобразования трёхмерной сцены в двумерное изображение.

Основные этапы:
1. Описание геометрии (вершины)
2. Преобразования (вращение, перемещение)
3. Проекция
4. Растеризация
5. Отрисовка пикселей
