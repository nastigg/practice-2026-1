Полезные ссылки

Инструменты и материалы для создания сайтов и веб-проектов.

Обучение HTML и CSS

📖 MDN Web Docs — Руководство для начинающих Официальная документация Mozilla. Лучшее место для изучения HTML, CSS и JavaScript с нуля. ↗ 🎓 HTML Academy Интерактивные курсы по вёрстке на русском языке. Подходит для полных новичков. ↗ 🌐 W3Schools Справочник с примерами по HTML, CSS, JavaScript. Удобно для быстрого поиска синтаксиса. ↗

Дизайн и прототипирование

🎨 Figma Главный инструмент для дизайна интерфейсов и прототипирования. Работает в браузере, бесплатно для студентов. ↗ 🎨 Coolors Генератор цветовых палитр. Помогает быстро подобрать гармоничную цветовую схему для сайта. ↗ 🔤 Google Fonts Бесплатные шрифты для веб-сайтов. Подключаются одной строкой кода. ↗

Хостинг и публикация

🚀 GitHub Pages Бесплатный хостинг для статических сайтов. Именно на нём опубликован наш сайт-образец. ↗ ⚡ Netlify Простой деплой сайта перетаскиванием папки. Бесплатный тариф покрывает большинство учебных проектов. ↗

Иконки и иллюстрации

✏️ Lucide Icons Открытый набор SVG-иконок. Минималистичный стиль, легко подключить в проект. ↗ 🖼️ unDraw Бесплатные SVG-иллюстрации для сайтов. Можно изменить цвет под свою палитру прямо на сайте. ↗

Справочные материалы

🛠️ CSS-Tricks Статьи и гайды по CSS: flexbox, grid, анимации и многое другое. Полезно на любом уровне. ↗ 🔍 Can I use Проверяет, поддерживается ли та или иная CSS/JS-фича в разных браузерах. ↗
